      Réglages

      Calendrier Google

      L'app lit ton agenda directement depuis ton navigateur. Rien n'est envoyé ailleurs, et aucun mot de passe n'est stocké. Il te faut un identifiant client OAuth, à créer une fois.

      Enregistré

      Où la page doit vivre

      Google n’autorise une connexion que depuis une adresse déclarée à l’avance, et l’aperçu dans Claude bloque les scripts extérieurs. Pour que le calendrier marche, cette page doit être hébergée à une adresse stable qui t’appartient. Le plus simple et gratuit : GitHub Pages. Tout le reste de l’app fonctionne sans cela.

      Comment l'obtenir

      1. Héberge d’abord cette page, puis reviens ici : l’adresse affichée en bas est celle à déclarer.
      2. Sur console.cloud.google.com, crée un projet.
      3. Dans la bibliothèque d'API, active Google Calendar API.
      4. Configure l'écran de consentement OAuth en type Externe, et ajoute ton adresse Gmail comme utilisateur de test.
      5. Dans Identifiants, crée un ID client OAuth de type Application Web.
      6. Dans Origines JavaScript autorisées, colle l'adresse affichée ci-dessous.
      7. Copie l'identifiant client et colle-le dans le champ ci-dessus.
