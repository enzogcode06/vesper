    Synchronisation entre appareils

    Tes tâches, habitudes et notes se mettent à jour toutes seules entre tes appareils. Pour que ce soit continu, utilise un dépôt GitHub privé : le jeton n'expire pas chaque heure. Sans cela, la synchronisation passe par ton Google Drive et demande de se reconnecter à Google toutes les heures.

    —

    Enregistré

    Créer le dépôt et le jeton

    1. Sur github.com, crée un dépôt privé nommé vesper-data.
    2. Réglages GitHub, Developer settings, Personal access tokens, Fine-grained tokens, puis Generate new token.
    3. Repository access : Only select repositories, uniquement vesper-data.
    4. Permissions, Repository permissions : Contents en Read and write.
    5. Génère le jeton, copie-le et colle-le ici. Ne le partage avec personne.

    Où la page doit vivre

    Google n’autorise une connexion que depuis une adresse déclarée à l’avance, et l’aperçu dans Claude bloque les scripts extérieurs. Pour que le calendrier marche, cette page doit être hébergée à une adresse stable qui t’appartient. Le plus simple et gratuit : GitHub Pages. Tout le reste de l’app fonctionne sans cela.

    Comment l'obtenir

    1. Héberge d’abord cette page, puis reviens ici : l’adresse affichée en bas est celle à déclarer.
    2. Sur console.cloud.google.com, crée un projet.
    3. Dans la bibliothèque d'API, active Google Calendar API et Google Drive API (pour la synchronisation).
    4. Configure l'écran de consentement OAuth en type Externe, et ajoute ton adresse Gmail comme utilisateur de test.
    5. Dans Identifiants, crée un ID client OAuth de type Application Web.
    6. Dans Origines JavaScript autorisées, colle l'adresse affichée ci-dessous.
    7. Copie l'identifiant client et colle-le dans le champ ci-dessus.
